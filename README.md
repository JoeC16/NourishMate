# Nourish Mate

A mobile-friendly Streamlit app for meal planning and dysphagia support.

## Features
- IDDSI level selector
- Dietary preference input
- AI-generated meal plans (OpenAI)
- Firebase Firestore integration

## How to Run
1. Connect this repo to [Streamlit Cloud](https://streamlit.io/cloud)
2. Add your `serviceAccountKey.json` as a secret
3. Add your OpenAI API key as a secret
4. Deploy and share your app

## Tech Stack
- Streamlit
- Python
- Firebase Firestore
- OpenAI API
